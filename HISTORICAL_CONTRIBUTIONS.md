# Historical contribution record

## Purpose

The repository adopted a public DCO process after its first alpha commit. This
file discloses the resulting historical gap; it is not a substitute for private
chain-of-title records and does not create a retroactive certification.

## Pre-beta audit

At commit `da30802afa080d12d1ecae8dd1856e340a14feb4`, the reachable `main`
history contained 186 commits. Nine commit messages contained a
`Signed-off-by:` trailer and 177 did not.

The missing trailers must not be manufactured by rewriting the published
`v1.0.0-alpha.1` tag or shared history. DCO is a public submission
certification; absence of a trailer is not by itself proof of ownership or
non-ownership.

## Release treatment

Before an official descendant release, an authorised MAGRATHEAN UK LTD
maintainer must:

1. enumerate historical authors and commit sources;
2. confirm the applicable founder, director, employment, contractor,
   assignment, or contributor record in private Company files;
3. resolve third-party and generated material through the public provenance
   manifest and release notices;
4. record approval of the historical baseline in the private release record;
5. require DCO sign-off for every new release-preparation commit.

This repository does not publish private agreements, signatures, addresses, or
identity documents. The signed release tag identifies the maintainer accepting
release responsibility; it does not replace the underlying records.
