# Teslatlas Home Assistant integration

Home Assistant integration for the public Teslatlas Hub protocol.

## Status

Foundation only. No integration code, manifest, or HACS package has been implemented.

## Purpose

Deliver a local-push, HACS-first integration through public APIs and event streams rather than embedding Home Assistant behaviour in Hub.
