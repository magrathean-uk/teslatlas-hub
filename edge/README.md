# Teslatlas edge

User-operated Fleet Telemetry ingress for Teslatlas Hub.

## Status

Foundation only. No receiver, spool, or deployment implementation has been added.

## Purpose

Provide an optional public Fleet Telemetry receiver for users whose home Hub cannot be internet-reachable. It is not a mandatory Magrathean relay.
