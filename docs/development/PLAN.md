# Hub plan pointer

In the maintained Teslatlas workspace, the programme plan is
`../docs/development/MASTER_PLAN.md` relative to the Hub root. That plan holds
current decisions, phase order, status and acceptance evidence.

There is no separate Hub status ledger. Older plans and archived receipts are
background only. A standalone Hub checkout does not include the workspace plan;
use the source and current task scope rather than inferring completion from old
notes.
