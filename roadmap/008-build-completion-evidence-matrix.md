# Build the completion evidence matrix

Blocked by: [Set account and vehicle scope](007-set-account-vehicle-scope.md).

## Question

What evidence proves every parity, reliability, migration, security, platform,
and performance claim?

## Starting recommendation

Create a traceable matrix from TeslaMate reference behavior to Hub test,
fixture, live rehearsal, and accepted deviation.

## Resolution

The [completion evidence matrix](../docs/COMPLETION_EVIDENCE_MATRIX.md) is the
release ledger. It separates implementation tests from corpus, native-platform,
owner-authorized live, and operator-rehearsal proof. No final claim closes
without immutable source and Hub revisions, reproducible command and input,
host/profile, expected-versus-actual result, redacted artifact, and any explicit
accepted deviation.
