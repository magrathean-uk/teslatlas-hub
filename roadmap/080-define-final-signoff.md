# Define final parity signoff

Blocked by: [Design the full parity rehearsal](079-design-full-parity-rehearsal.md).

## Question

Who may declare Hub a complete TeslaMate backend replacement for Teslatlas,
which evidence must be current, and which residual deviations block release?

## Starting recommendation

Require every matrix row closed with current evidence, zero unexplained data
differences, successful migration rollback, and explicit acceptance of each
documented deviation.

## Resolution

Only a named accountable release authority may sign final approval, bound to
every current evidence artifact. Unexplained difference, missing hard gate,
unsafe deviation, stale evidence, or later failure blocks or supersedes it.
Signoff is readiness only; production cutover remains an explicit operator act.
