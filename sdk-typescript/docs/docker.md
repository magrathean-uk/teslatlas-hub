# Docker package gate

The Docker package gate was retired on 2026-10-08 in plan group G2-2, together with
the Docker lane, the package-provenance and lifecycle scripts, the pinned image and
platform records under `tools/`, and the examples. The package is private and not
published in v7, so no Docker or registry lane replaces it.

Receipts that the gate produced stay under [`development/`](development/). They record
what an earlier source revision did and are not evidence for the current one.
