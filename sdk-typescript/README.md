# Teslatlas TypeScript SDK

Public browser and Node.js SDK for the Teslatlas Hub protocol.

## Status

Foundation only. No runtime client implementation or generated API code is present.

## Purpose

This SDK will power the open reference viewer and give third-party JavaScript and TypeScript clients one supported path to the public Hub protocol.
