# Product versioning

Viewer carries the shared ecosystem product version `2026.36.2` in its npm
manifest, lockfile, and `public/version.json` build metadata. The calendar
number identifies a candidate release cohort; it does not establish Hub wire
compatibility.

`compatibility/hub.json` binds the candidate to `hub-http-v1@1.0.0`, profile
SHA-256 `b3914d35d28374f6423af789e9ed6a4a4c82196a068c041946e24d609db0b05b`.
Tested Hub versions, source fingerprints, and compatibility receipts remain
empty until the ecosystem-wide compatibility matrix is accepted.
